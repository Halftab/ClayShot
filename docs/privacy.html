POLICY

Privacy policy

This page describes the current intended privacy approach for ClayShot. It should be reviewed and updated to match the final published app and any services it uses.

Information collection

ClayShot is not intended to require an account. This website does not include its own analytics, advertising trackers or account forms.

Device permissions

Some mobile gameplay features may request motion or sensor access so the device can be used for aiming. Such access should be used only for the relevant gameplay feature.

Third-party services

Repository hosting and file downloads are provided by GitHub and are subject to GitHub's own privacy practices.

Contact

For questions about this policy or the project, use the contact or discussion method provided on the ClayShot GitHub repository.

Before publishing the app widely, confirm this policy against the app's actual permissions, networking, analytics and data-handling behavior.
