# ClayShot

ClayShot is an immersive, browser-based clay target shooting game. Take aim, read the changing wind, and break flying clay targets across a choice of outdoor shooting grounds.

## About the game

ClayShot is built around the feel of a sporting clay shooting range. Targets launch into the scene and the player must track and shoot them while accounting for the wind. Accurate shots build streaks, while missed shots affect the round's results.

Choose your shooting ground:

- **Countryside** — open green fields
- **Mountain** — a dusky mountain setting
- **Coastal** — a sunny shoreline environment

Each setting gives the range its own atmosphere.

## Game modes

- **Classic** — play a set round of 25, 50, or 100 targets.
- **Endless** — keep shooting against an unlimited stream of targets and try to improve your run.
- **Scores** — review personal records and recent results.

## Aiming and controls

Choose the aiming method that suits your device:

- **Touch** — aim on the screen and tap to shoot.
- **Gyroscope** — tilt a compatible Android device to move your aim, then tap to shoot. Horizontal and vertical sensitivity can be adjusted separately.

On desktop, use the browser's pointer to aim and click to shoot.

## Features

- 3D shotgun and shooting-range presentation
- Moving clay targets and break effects
- Changing wind direction and strength
- Hit streaks, round statistics, and personal records
- Three outdoor shooting environments
- Adjustable game volume
- Responsive browser and Android layouts

## Running the game

Open `index.html` in a modern browser, or serve the project directory with a local static web server.

The Android build is provided as `app-debug.apk`. It is a debug APK for testing and installation on compatible Android devices.

## Project contents

- `index.html` — browser game
- `app-debug.apk` — Android debug build
- `assets/audio/` — game sound and ambience files

Audio files should retain their relative paths when the project is moved or hosted, so the game can load them correctly.
